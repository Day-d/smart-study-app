# Smart Study App 📚

A minimalist study productivity tracker built with Python, Flask, and SQLite. Features real-time timers, task management, and smart study reminders to help students stay organized and efficient.

## Features
- **Task Management:** Add, track, and complete study assignments.
- **Focus Timer:** Built-in timer to keep your study sessions organized.
- **Smart Reminders:** Real-time feedback for study sessions.
- **Responsive UI:** Modern, dark-themed interface.

## Tech Stack
- **Backend:** Python (Flask)
- **Database:** SQLite
- **Frontend:** HTML5, CSS3, JavaScript
